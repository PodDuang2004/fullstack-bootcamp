AI / Data Project

ระบบแชทบอทให้คำปรึกษาด้านการวางแผนภาษีเงินได้บุคคลธรรมดา

  • เครื่องมือและโมเดล: Python, RAG Pipeline, Llama, Hugging Face, FAISS, Dialogflow ES, OpenCV, Tesseract OCR, Firebase, RESTful API
  • ระบบสืบค้นเชิงความหมาย (RAG): วางสถาปัตยกรรมแปลงข้อความเป็นเวกเตอร์ด้วย Embedding Model ร่วมกับ FAISS ดึงข้อกฎหมายและประมวลรัษฎากรส่งต่อให้โมเดล Llama ตอบคำถามได้แม่นยำ ลดความคลาดเคลื่อนของข้อมูล
  • ประมวลผลภาษาธรรมชาติ (NLU): จำแนก Intent และสกัด Entity ผ่าน Dialogflow ES เชื่อมต่อ LINE Messaging API รองรับการถาม-ตอบแบบ Multi-turn เพื่อเก็บข้อมูลรายได้และค่าลดหย่อนอย่างเป็นขั้นตอน
  • โมดูลคำนวณและสกัดข้อมูลจากภาพ (OCR): เขียนตรรกะคำนวณภาษีเบื้องหลังด้วย Python และใช้ OpenCV ร่วมกับ Tesseract OCR ดึงข้อมูลจากเอกสารบริจาคอิเล็กทรอนิกส์ (E-Donation) โดยอัตโนมัติ
  • ฐานข้อมูลและออกรายงาน: จัดเก็บประวัติและบริบทการสนทนาบน Google Firebase (NoSQL) พร้อมระบบสังเคราะห์รายงานภาษีเป็นไฟล์ PDF อัตโนมัติด้วย ReportLab
Python LLM / RAG FAISS OpenCV & OCR Firebase LINE API
Full-Stack Web Development

Basketball Hub - แพลตฟอร์มจัดการและจองสนามบาสเกตบอล

แพลตฟอร์มบริหารจัดการและจองสนามบาสเกตบอลแบบครบวงจร พร้อมระบบตรวจสอบสถิติผู้เล่น ออกแบบ UI/UX บน Figma และพัฒนาแอปพลิเคชันแบบ Full-Stack ที่ปลอดภัยและมีระบบป้องกันการจองซ้ำ

  • สถาปัตยกรรมระบบ & UI/UX: ออกแบบ Flow การทำงานแบบ End-to-End และทำ Prototype บน Figma ครอบคลุมการจองสนาม สถิติผู้เล่น และตารางการใช้งาน
  • พัฒนา Frontend: สร้างหน้าเว็บด้วย React.js แบบ Reusable Components (เช่น CourtCard, BookingForm, Scoreboard) จัดการ State ภายในระบบให้ตอบสนองลื่นไหล
  • พัฒนา Backend & API: พัฒนา RESTful API ด้วย Node.js / Express เพื่อจัดการ Business Logic, ตรวจสอบสิทธิ์เข้าใช้งาน (Authentication) และป้องกันการจองสนามซ้ำซ้อนในเวลาเดียวกัน
  • จัดการฐานข้อมูล: ออกแบบ Schema สำหรับจัดเก็บข้อมูลผู้ใช้ รายละเอียดสนาม และประวัติการทำรายการอย่างเป็นสัดส่วน
  • Version Control: ติดตามและจัดการเวอร์ชันซอร์สโค้ดตามมาตรฐาน Git Workflow ผ่าน GitHub
React.js Node.js Express RESTful API MySQL / MongoDB Figma Git
